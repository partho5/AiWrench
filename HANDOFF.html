Your Dashboard

Where the API lives and how to check on it.

🚂

Railway (Hosting)

  • ● Go to your Railway dashboard to see if the service is running
  • ● Restart: Click the service → three dots → Restart
  • ● Logs: Click the service → "Logs" tab to see live activity
  • ● Deploys happen automatically when code is pushed to main
💚

Health Check

Open this URL in any browser to confirm the API is alive:

GET  https://<your-railway-url>/health

If you see "status": "ok" — everything is fine.

If you see nothing or an error, the service needs a restart on Railway.

Costs & Billing

Lowest cost per request

Highest per-request — used only when needed
Cost optimization is built in: Claude Opus (the expensive one) is only called for complex cases — images, PDFs, fault codes, and safety topics. Simple conversations use cheaper models. First messages use the cheapest model available.

API Endpoints

What the API exposes. Convex calls these automatically — you don't need to call them yourself.

GET /health Returns OK if the service is running
POST /enrich Main chat — diagnosis and advice (streaming)
POST /vision Image analysis — reads photos of parts/damage
POST /classify Categorizes an asset (vehicle/equipment type)
POST /classify/refine Dual-pass classification — retries if confidence is low

When Things Go Wrong

Error codes and what to do about them.

401 Unauthorized

The API token sent by Convex doesn't match. Check that API_SECRET_TOKEN is identical in both Railway and Convex.

429 Too Many Requests

Rate limit hit. Either too many users or a misbehaving client. Increase RATE_LIMIT_RPM in Railway if this happens often during normal usage.

500 "Grok API error"

The Grok API key is expired, invalid, or out of quota. Go to console.x.ai, check your key, and update GROK_API_KEY in Railway if needed.

500 "Claude API error"

Same as above but for Anthropic. Check at console.anthropic.com and update ANTHROPIC_API_KEY.

??? No response at all

The service may have crashed or Railway is down. Go to Railway dashboard → check if the service shows "Active". If not, click Restart. If the health check URL works but endpoints don't, check Railway logs for error details.

Security Rules

Non-negotiable rules to keep the system safe.

Never Do

  • Share API keys in emails, Slack, or screenshots
  • Disable the auth middleware
  • Expose the Railway URL publicly (only Convex should call it)
  • Commit keys to the git repository

Always Do

  • Rotate API keys every 90 days or immediately if compromised
  • Keep Convex's token in sync with Railway's API_SECRET_TOKEN
  • Monitor AI provider dashboards for unexpected spikes
  • Keep Railway service on a paid plan for uptime SLA
